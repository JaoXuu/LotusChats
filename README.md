## 🔑 Plugin Permissions

| Permission                     | Description                              |
|--------------------------------|------------------------------------------|
| `lotuschat.admin`              | Full access to everything                |
| `lotuschat.reload`             | Reload the plugin                        |
| `lotuschat.chat.colors`        | Use & color codes in chat                |
| `lotuschat.chat.formats`       | Use & format codes in chat               |
| `lotuschat.chatcolor`          | Open the /chatcolor GUI                  |
| `lotuschat.chatcolor.*`        | Access all colors, formats and hex       |
| `lotuschat.chatcolor.hex.custom` | Enter a custom hex color via chat     |
| `lotuschat.chatcolor.hex.custom-gradient` | Enter a custom gradient via chat |
| `lotuschat.display.cooldown.bypass` | Bypass display cooldowns           |
| `lotuschat.filter.bypass`      | Bypass the chat filter                   |
| `lotuschat.spy`                | See all private messages                 |
| `lotuschat.msg.bypass`         | Message players with DMs disabled        |
